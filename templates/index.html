BEHIND THE ROUTE

Meet the algorithms

Two classic AI search strategies, each with a different way to reason.

A*INFORMED SEARCH

A* Search

Ranks each candidate city by the cost already traveled plus an admissible estimate to the goal. The lowest f-score gets explored first.

f(n) = g(n) + h(n)
Actual path costEstimated remaining cost
  • Optimal for non-negative edge costs
  • Supports distance, cost and time objectives
  • Tracks explored nodes and route steps
AO*AND-OR SEARCH

AO* Search

Solves a problem-reduction graph: an AND node needs every child; an OR node selects its least-cost child. Costs back up to find the best solution graph.

AND: Σ child costs · OR: min(child costs)
Every required segmentBest alternative
  • Handles dependent travel legs
  • Compares alternate road plans per leg
  • Shows selected decisions and explanations

PROJECT DOCUMENTATION

Project notes

A concise guide to the problem, design, methodology and next steps.

Abstract & introduction ＋

This Intelligent Travel Planner models South Indian cities as a weighted road graph and applies informed AI search to find practical trips. A* recommends optimal paths for distance, estimated cost or journey time; AO* evaluates dependent journey legs and route alternatives through an AND-OR graph. It runs locally on predefined sample data without paid services or API keys.

Problem statement & objectives ＋

Choosing a road route among many connected cities is a weighted search problem. The objectives are to model a road network, implement A* and AO* in Python, compare routes against travel preferences, and make each algorithm's decisions observable.

Existing & proposed system ＋

Manual planning or basic map lookups can obscure trade-offs and provide little insight into search decisions. The proposed local web app combines a configurable graph, real search algorithms, route estimates, alternatives, and an interactive visual trace.

System architecture & methodology ＋

Browser UI (HTML/CSS/JavaScript) → Flask JSON API → Python graph and search module → predefined road data. The planner validates inputs, runs A* and AO*, then returns paths, metrics and explanation steps for SVG visualization.

A* algorithm ＋

Initialize a priority queue with the start state; repeatedly expand the lowest f(n)=g(n)+h(n); relax each valid road edge; advance ordered waypoint progress; stop at the goal and reconstruct predecessors. The straight-line estimate is scaled conservatively for each objective.

AO* algorithm ＋

Represent the complete trip as an AND node over required legs, each leg as an OR node over candidate routes, and each route as an AND node over its road segments. Sum costs at AND nodes, choose the minimum-cost child at OR nodes, and back up the selected solution and explanation.

Applications & advantages ＋

Applications include road-trip planning, logistics, navigation education and decomposable planning problems. The approach is transparent, configurable, locally runnable, multi-objective and demonstrates two foundational AI search methods.

Future scope & conclusion ＋

Future work could add live traffic, public transit, richer geographic maps, time windows, user-defined networks and persistent trip plans. This project demonstrates how heuristic search and AND-OR decomposition can support explainable travel decisions using an immediately available sample network.

ⓘ Road distances, average speeds and per-kilometer costs are illustrative sample data—not live traffic, fare quotes or navigation guidance.
